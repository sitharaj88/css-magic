# 📟 Day 4: Holographic Geometric Pulse

A cutting-edge loading animation that utilizes abstract digital energy, 3D wireframe geometry, and holographic CRT effects. This project explores high-tech aesthetics without relying on traditional glassmorphism or literal physics.

## ✨ Features

- **3D Wireframe Geometry**: Rotating CSS-based cube with internal accent details.
- **Holographic Overlays**: Realistic scanlines, vignetting, and digital noise filters.
- **Pulsing Energy Core**: A central glowing attractor with expanding electromagnetic waves.
- **Digital HUD Elements**: High-tech monospace readouts including binary streams and data rings.
- **Pure CSS Animation**: Automated 10-second loop with systemic "flicker" instability.

## 🚀 Technical Highlights

- **`preserve-3d`**: Complex 3D transformations for the rotating wireframe.
- **CSS Animations**: Tiered rotations and expansion loops for multi-layered energy effects.
- **SVG Filters**: Custom turbulence noise integrated directly via inline data URIs.
- **Holographic Aesthetic**: High-contrast black/neon-cyan palette for that scifi/cyberpunk feel.

## 🛠️ Usage

Simply open `index.html` in any modern browser to view the holographic simulation.

```bash
open index.html
```
